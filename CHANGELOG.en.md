## v0.1.0 — 2026-10-27

First private development baseline:

- Separate reference-location search from design-boundary confirmation, with independent project naming.
- Query important places by city and output extent; rank annotations and allow manual refinement.
- Light, Moss, Dark, and Satellite styles in a large-map workspace with floating tools.
- Solid and dashed lines, arrows, areas, text, undo, and redo.
- PNG/SVG export of the current output frame, browser saving, and JSON import/export.
- Standard npm installation, locked dependencies, local checks, and an agent entry point.

Release preparation excluded personal credentials, caches, and development-process materials without modifying the running development copy. See [Validation record](docs/validation.en.md) for the scope of testing.
