# 场地分析工具 · v0.1.0

简体中文 | [English](README.en.md)

面向建筑前期设计的本地地图工作台。搜索参照地点、圈定设计场地，自动查询周边重要地点，手动微调后输出单张高清分析图。

英文版为仓库使用文档；当前应用界面仍为中文。

## 快速启动

准备 Node.js 22 或 24（附带 npm）、现代浏览器和网络。在本目录运行：

```sh
npm ci
npm test
npm run check
npm start
```

打开 http://127.0.0.1:4173/ 。通过页面“地图配置”填写自己的高德 Web 端 JS API Key 和配套安全密钥。不要把密钥填入代码或提交 Git。

本地配置保存于 `.local/amap.json`，该目录已被 Git 排除。未配置时可打开工作台，但真实搜索、卫星影像和周边查询需要有效凭证。当前只监听本机，不是部署到公网的网站。

## 操作流程

1. 搜索城市、地址或附近学校等参照地点；搜索词不作为项目名。
2. 平移地图找到真实地块，绘制矩形或多边形，明确确认设计场地，并填写项目名。
3. 独立调整城市出图范围，再生成区位分析；系统按城市和范围查询交通枢纽、商业中心、公园及公共设施，筛选、分级并排布名称。
4. 选择浅色线稿、苔绿、深色线稿或卫星风格。拖动或修改标注，按需绘制实线、虚线、箭头、区域和文字。
5. 导出当前出图框对应的 PNG / SVG；默认高清 PNG 为 4800 × 3600。地图署名保留，浮动控件不出图。
6. 项目保存在当前浏览器，可下载与导入 JSON 备份；没有账号和云端保存。

## 仓库结构

```text
serve.mjs              本机服务、配置、地图代理
analysis.mjs           查询编排及分析接口
discovery.mjs          地点筛选、分级、去重
basemap-service.mjs    动态地图范围与图层
dist/                  直接维护的前端源码与底图资产
tests/                 自动化回归测试
vendor/                随包依赖与原许可证
samples/               杭州、良渚测试数据
scripts/               环境检查和本机服务验证
docs/                  架构、操作验收与分发说明
SKILL.md               Agent 复用入口
```

**没有额外的前端编译步骤，`dist/` 不是可随意删除的构建缓存。** 随包杭州地图数据用于首屏与回归复现，因此仓库包含必要地图资产；新区域按当前取景联网加载。

## 当前边界

- 自动识别基于地点接口查询和规则筛选，不是从影像推断真实用地边界。设计红线必须由用户确认。
- 卫星导出依赖高德图层、网络及浏览器是否允许读取。发生跨域或超时时应明确报错，不保证任意环境都成功。
- SVG 中底图是内嵌栅格影像，分析与手绘为矢量；不是全矢量地图。
- 本版本以 Windows / Node 24 验证为准，测试替身不等于真实地图及浏览器完整验收。
- 暂无多人系统、登录、支付、访问统计或公网部署；本次仅保存私有源码版本。

## Agent 使用

让 Agent 读取根目录 `SKILL.md` 和 `AGENTS.md`，随后执行安装、测试与本机启动。不要要求提供聊天中的密钥，也不要以接口或测试数据绕过用户确认场地。
