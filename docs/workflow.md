# 场地工作流与验收

## 输入与交互

1. 搜索城市、地址或附近地标。搜索结果只帮助定位；可以搜索小学后移到相邻真实地块。
2. 用户填写项目名称，矩形/多边形圈定设计场地；由用户确认真实边界。没有边界时请用户在地图圈定，不把测试矩形当实测红线。
3. 点击确认。随后独立调整城市展示范围与出图比例。
4. 自动分析：按场地所在城市与当前范围查询交通枢纽、商业中心、公园景观、公共设施；去重、排序、分级、排布。查询失败必须如实显示。
5. 手动拖动文字、修改名称、隐藏地点，或画直线、折线、箭头、区域及文字；线型支持实线和虚线。
6. 选择浅色线稿、苔绿、深色线稿或卫星模式。卫星以灰度影像为底、彩色分析叠加；距离圈应清晰。
7. 导出高清 PNG；线稿还可导出内嵌底图 SVG。卫星是否支持当前导出格式以运行版本为准，不承诺离线原始影像下载。
8. 下载 JSON 项目备份，再导入确认名称、边界和微调保留。浏览器自动保存只属于该设备、浏览器和站点来源。

## 自动化验证

npm test 覆盖控制器、代理、输入验证、分类筛选、跨城市数据处理、命名、取消、存储冲突和图面合成。测试素材中的杭州/良渚只是回归样本，不是任意地点查询的替代答案。

## 真实浏览器清单（每次交付标明哪些已实测）

- 未确认场地不能生成或导出；重新画边界使确认失效。
- 搜索附近学校 → 移动 → 圈定另一地块 → 项目名“测试住宅项目” → 确认 → 分析；SITE 保持项目名。再搜其他地标不会改名。
- 用杭州之外的新案例测试，重要节点与所处城市、出图范围一致；候选列表可隐藏和手动调整。
- 四种风格切换可见变化；操作区 1.2 倍、图例及比例尺原尺寸，工具不遮住必要操作。
- 拖动文字不会移动地理定位点；撤销、重做、线型和取消编辑有效。
- PNG 实际下载，打开确认底图和标注都有、没有工具栏；查看像素尺寸，核对与出图框一致。尤其单独测试卫星导出。
- JSON 导入/导出恢复编辑状态；新建不携带上一场地的名字和边界。
- 短屏、缩放、长地名、网络失败的提示仍能操作。

禁止用 AI 生成的地图截图代替真实出图。没有浏览器控制权限时，可以让使用者操作并报告；分别标注代码测试通过与视觉尚未验证。
